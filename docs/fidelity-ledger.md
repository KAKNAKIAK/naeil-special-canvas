# 시안 대비 구현 점검

| 비교 항목 | 기준 시안 | 실제 구현 | 판단 |
|---|---|---|---|
| 앱 골격 | 상단 도구, 좌측 라이브러리, 중앙 720px, 우측 속성 | 동일한 4영역과 하단 상태바 | 일치 |
| 색상·밀도 | 흰 패널, 회색 작업면, 내일투어 teal | 동일 토큰, coral 경고 추가 | 일치 |
| 블록 편집 | 선택 테두리와 떠 있는 조작바 | 이동·복제·삭제 조작바 구현 | 일치 |
| 이미지 영역 | 별도 자산 그리드와 출처 속성 | 업로드·블록 연결·권리·승인·증빙 편집 | 기능 확장 |
| 전달 단계 | 내부 시안/고객 최종본 토글 | 검수 탭에서 전환하고 최종본 오류 차단 | 기능 확장 |
| 샘플 이미지 | 몰디브 사진이 채워진 목업 | 권리 불명 이미지는 넣지 않고 플레이스홀더 사용 | 의도적 차이 |
| 모바일 | 데스크톱 기준 시안 | 48% 자동 맞춤과 좌우 드로어 | 기능 확장 |
