# 디자인 기준

## 한줄 결론

문서 편집기의 익숙함과 720px 여행 상세페이지 미리보기를 결합한 조용한 실무형 캔버스다.

## 화면 구조

- 상단 56px: 프로젝트명, 저장 상태, 실행 취소, 미리보기, 내보내기
- 왼쪽 292px: 도구 레일 + 블록·이미지·레이어 라이브러리
- 중앙: 회색 작업면 위 720px 흰색 상세페이지
- 오른쪽 324px: 선택 블록 속성 및 납품 검수
- 하단 40px: 자동 저장, 자산 수, 확대 비율

## 토큰

- Brand teal `#07858B`, deep teal `#066C72`
- Highlight coral `#E46555`
- Workspace `#EEF1F2`, border `#DCE3E5`
- Canvas serif: Noto Serif KR, UI: Noto Sans KR
- UI radius 7–9px, 패널은 평면, 캔버스에만 낮은 그림자

## 원칙

- 기획 정보는 DOM 텍스트로 유지해 편집·검색·HTML 전달이 가능해야 한다.
- 장식보다 블록 위계, 이미지 크롭, 디자이너 메모가 먼저 보인다.
- 내부 시안과 고객 최종본의 이미지 검수 기준을 분리한다.
